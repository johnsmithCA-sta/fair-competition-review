# fair-competition-review · 公平竞争审查（政策措施）

> **Turn a draft policy into a review report where every flagged clause traces back to the exact legal provision.**
> **把一份政策草案，变成一份每条风险都能回溯到法条原文的审查报告和《公平竞争审查表》。**

`公平竞争审查` · `政策措施` · `合规审查` | MIT License | Python 3.8+ (stdlib only)

---

## ✨ Why / 为什么需要它

《公平竞争审查条例》（2024-08-01 施行）与《实施办法》（2025-04-20 施行）落地后，各级政府及其部门拟出台的政策措施都要过公平竞争审查。实操里有两件难事：

1. **标准细、条数多**——四类禁止标准下挂 66 项细化标准，靠人脑逐条对，漏项是常态；
2. **结论要能交代**——审查意见写出去要经得起督查抽查，每条风险都得说清"违反哪一条、依据是什么、改怎么改"。

这个技能把这两件事做成流水线：**逐条扫描 → 标注风险等级 → 挂上可点击的法条原文 → 出报告和审查表 → 一键转 Word**。

## 🆚 Comparison / 与相邻方案的关系

> 下表只描述**能力类别**，不点名任何具体产品——选型看的是定位差异。

| 类别 | 典型形态 | 与本品的关系 |
|---|---|---|
| **通用文档合规审查** | 按关键词命中给出检查清单 | **不同层**。本品的判定锚在 66 项具体审查标准上，每条结论带标准编号，可回溯到法条原文 |
| **招投标 / 政府采购文件审查** | 面向招标方或采购方的合规检查 | **相邻，不重叠**。审查对象是**政策措施**（规章、规范性文件草案），不是单个采购项目文件 |
| **企业侧合规自查** | 站在经营者视角排查自身风险 | **视角相反**。本品站在**审查主体**视角，审的是政府拟出台的政策 |
| **法条检索工具** | 按条号取法条原文 | **互补**。本品用法条检索做溯源，核心价值在扫描、定级与成文 |

**One-liner / 一句话定位**：*不是"帮你查法条"，是"帮你把一份政策草案过完审查、写清依据、出好文书"。*

## 🎯 What it does / 它做什么

| # | 能力 | 说明 |
|---|---|---|
| 1 | **审查范围判定** | 按《条例》第 2 条、《实施办法》第 2 条判断输入文本是否属于应审查的政策措施；不属于的出具说明并写明理由 |
| 2 | **四类标准逐条扫描** | 四类 18 项 + 66 项细化标准，先关键词预筛定位、再逐条语义核对 |
| 3 | **风险分级定位** | 每条风险记录：条款位置、原文摘录、违反标准编号、风险等级（明显违反 / 疑似 / 提示）、修改建议 |
| 4 | **法条依据溯源** | 每条风险标注「法规全称 + 条号 + 原文链接」；未收录的法规走降级链并注明来源 |
| 5 | **例外情形判断** | 按《条例》第 12 条论证四项情形与三项要件，不把可论证保留的条款直接判死 |
| 6 | **地方规则适配** | 按用户地域叠加地方细则要求 |
| 7 | **审查表输出** | 官方通用格式《公平竞争审查表》，四类逐项「是 / 否」，可直接作为发文程序附卷材料 |
| 8 | **报告与 Word 输出** | 六段固定结构，含法条依据索引汇总表；报告与审查表均可一键转 `.docx`（标题、表格、加粗全部保留） |

## 📂 审查依据体系（三层）

| 层级 | 文件 | 作用 |
|---|---|---|
| 法律 | 《反垄断法》 | 上位依据 |
| 行政法规 | 《公平竞争审查条例》第 8—11 条 | 四类禁止标准 + 第 12 条例外 |
| 部门规章 | 《公平竞争审查条例实施办法》第 9—23 条 | **66 项细化标准** |
| 地方 | 各省《重要政策措施公平竞争审查工作办法》等 | 程序与本地增补要求 |

## 🚀 Quick start

```bash
# 1. 提取政策正文（docx / txt / md）
python3 scripts/extract_text.py 政策草案.docx --out policy.txt

# 2. 关键词预筛，拿到疑似位置清单
python3 scripts/scan_rules.py policy.txt --format md --out prescreen.md

#    只想看高危信号、过滤泛词噪音：
python3 scripts/scan_rules.py policy.txt --strong-only

# 3. 对全文逐条语义核对 → 逐条挂法条依据 → 出报告与审查表

# 4. 要 Word 版就直接转（标题与表格格式保留）
python3 scripts/export_docx.py 公平竞争审查表_XX办法.md --out 审查表.docx
```

> ⚠️ **预筛只是定位助手**：命中不等于违规，**零命中也不等于无风险**——两种情况都要回原文逐条核对。

## ⚙️ 工作流

1. **输入与范围判定** —— 取正文、确认适用地域、判断是否属于「涉及经营者经济活动」的政策措施。
2. **四类标准逐条扫描** —— 预筛定位 + 全文语义核对 + 三个前置问题定级。
3. **法条依据核验与溯源** —— 带文号的精确法规名取原文，核对返回值，生成可点击链接。
4. **例外情形判断** —— 对拟保留条款论证第 12 条例外三要件。
5. **输出** —— 审查报告 + 审查表，需要时转 `.docx`。

## ⛔ 不适用

- 反不正当竞争执法案件办理、经营者集中申报；
- 企业自身的竞争合规自检；
- 招投标文件、政府采购文件的合规审查。

> 本技能输出为**审查工作辅助参考**，不构成法律意见，不替代起草单位审查岗与市场监管部门的会审意见；所有结论须经人工复核后方可形成正式审查结论。
