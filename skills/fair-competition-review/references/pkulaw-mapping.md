# 北大法宝溯源用法（含实测坑）

> 目标：让审查报告里**每条风险的法条依据都能一键跳转官方原文**。本文档含已验证的调用方式与陷阱。

## 一、可用工具

| 工具 | 参数 | 用途 |
|---|---|---|
| `get_law_item_content` | `title` + `tiao_num`（阿拉伯数字，如 9） | 取某法某条原文，返回全文 + `Url` |
| `get_article` | `title` + `number`（中文条号，如"第九条"） | 同上 |
| `get_law_list` | `title` + `effectiveness` / `timeliness` | 元数据核验（文号/日期/位阶） |
| `search_article` | `text` + `lib` / `timeliness` | 语义检索定位（用于找地方细则） |

**返回的 `Url` 字段即可引用的原文链接，原样写入报告。**

## 二、常用条文链接

| 法规 | 条文 | 原文链接 |
|---|---|---|
| 公平竞争审查条例 | 第8—12条 | `https://pkulaw.com/chl/af627701160484f2bdfb.html` |
| 公平竞争审查条例实施办法 | 第9—23条 | `https://www.pkulaw.com/chl/543b6ea27fc36a94bdfb.html`（条文锚点如 `#tiao_9.0`） |
| 公平竞争审查制度实施细则（2021） | 第17条 | `https://pkulaw.com/chl/00db3f8e67b71091bdfb.html` |
| 公平竞争审查条例实施办法（99号令元数据） | — | DocumentNO=国家市场监督管理总局令第99号；施行 2025-04-20 |

> 链接随平台改版可能失效；**报告里以工具本次返回的 `Url` 为准，本表只作对照**。

## 三、⚠️ 已知陷阱（必读）

1. **title 模糊匹配会错位**：用简称调用 `get_law_item_content(title="公平竞争审查条例", tiao_num=9)`，**可能返回《公平竞争审查条例实施办法》第九条**——两者的"第 X 条"内容完全不同。
   - **后果**：若不核对，会把实施办法条文当成条例条文引用，**报告法条依据直接错误**。
   - **对策**：① 用**带文号的精确 title**（如 `公平竞争审查条例（国务院令第783号）`）；② 每次调用后**校验返回的 `Title` 与 `DocumentNO` 是否与目标一致**，不一致则视为落空、换精确名称重试；③ 拿不到就回落，不得凭记忆补。

2. **同名文件混杂**：检索"公平竞争审查制度实施细则(暂行)"会命中地方同名文件。核对 `IssueDepartment` / `DocumentNO` 是过滤手段。

3. **地方规范性文件大量未收录**：省级 / 地市《公平竞争审查制度实施办法（暂行）》类文件多未收录，无法调取。此时回落到本地法规依据文件或政府官网，并注明来源。

4. **纪律**：单次调用 ≤10 条；禁止循环批量抽取拼接数据集；401 / 90001 = 订阅未生效，不重试。

## 四、标准 → 条号映射（报告标注用）

| 上报标准 | 《条例》 | 《实施办法》 |
|---|---|---|
| 一类 市场准入退出 | 第8条 | 第9—12条 |
| 二类 要素自由流动 | 第9条 | 第13—17条 |
| 三类 生产经营成本 | 第10条 | 第18—20条 |
| 四类 生产经营行为 | 第11条 | 第21—23条 |
| 兜底 | — | 第24条 |
| 例外 | 第12条 | 第25条 |

报告中的链接写法（示例）：
```
法条依据：《公平竞争审查条例》第十条第（二）项 —— [原文](https://pkulaw.com/chl/af627701160484f2bdfb.html)
```

## 五、降级链

法宝可用 → 取原文 + 链接；法宝未收录 / 匹配失败 → 本地法规依据文件（如公平竞争审查法规依据库中的对应文件）→ 政府官网原件。**任何一级降级都要在报告"来源"栏注明；缺来源的风险不写入结论。**
