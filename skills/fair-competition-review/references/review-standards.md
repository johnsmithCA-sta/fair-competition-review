# 审查标准完整清单（四类 66 项）与预筛规则

> 规则底座。**条文以法规原文为准**（官方公布文本，或本地法规依据文件），本文件是结构化索引与判别要旨，不得凭记忆改写条文。
> 依《公平竞争审查条例实施办法》（总局令第99号）第9—23条逐条清点，共 **66 项**。

## 一、位阶与适用范围

| 层级 | 文件 | 用途 |
|---|---|---|
| 法律 | 《反垄断法》 | 上位依据 |
| 行政法规 | 《公平竞争审查条例》（国务院令783号）第8—11条 | 四类禁止 + 第12条例外 |
| 部门规章 | 《条例实施办法》（总局令99号）第9—23条 | **66 项细化标准**（本文件主体） |

适用判定（办法第2条）：**涉及经营者经济活动**的政策措施——市场准入和退出、产业发展、招商引资、政府采购、招标投标、资质标准、监管执法等；含政策性文件、标准、技术规范、行政协议、备忘录。

## 二、66 项完整清单

### 第一节 限制市场准入和退出（19 项）
**办法第9条 · 违法设置市场准入审批程序（6项）**
1. 负面清单之外违规制定市场准入性质负面清单
2. 负面清单之外违规设立准入许可，或以备案/证明/目录/计划/规划/认证等方式要求申请获批后方可经营
3. 违法增加审批环节程序，或设置具有行政审批性质的前置备案
4. 违规增设市场禁入，或限制资质、所有制、股权比例、经营范围、业态、商业模式
5. 违规采取临时性市场准入管理措施
6. 其他

**办法第10条 · 违法设置或授予政府特许经营权（4项）**
1. 无法定依据或未经国务院批准设置特许经营权/以特许经营名义增设行政许可
2. 未通过招标、谈判等公平竞争方式选择特许经营者
3. 违法约定或未经法定程序变更特许经营期限
4. 其他

**办法第11条 · 限定经营/购买/使用特定经营者商品（5项）**
1. 以明确要求、暗示等方式限定
2. 通过限定所有制、注册地、组织形式或其他不合理条件限定
3. 通过设置不合理项目库、名录库、备选库、资格库限定
4. 通过奖励性/惩罚性措施限定
5. 其他

**办法第12条 · 不合理或歧视性准入退出条件（4项）**
1. 设置明显不必要或超出实际需要的准入条件
2. 根据所有制、注册地、组织形式、规模等设置歧视性准入/退出条件
3. 在注销、破产、挂牌转让等方面违法设置退出障碍
4. 其他

### 第二节 限制商品、要素自由流动（23 项）
**办法第13条 · 限制外地商品要素进入/阻碍本地经营者迁出（4项）**
1. 对外地或进口商品设差异技术要求、检验标准、更多检验频次，或重复检验认证
2. 设关卡或其他手段阻碍外地商品要素进入、本地商品要素输出
3. 违法设审批或不合理条件妨碍变更注册地址、减少注册资本，或对本地经营年限提要求
4. 其他

**办法第14条 · 排斥限制强制外地经营者本地投资/设分支机构（4项）**
1. 强制、拒绝或阻碍外地经营者在本地投资经营或设分支机构
2. 对投资规模、方式、产值、税收或分支机构的商业模式、组织形式作不合理限制/要求
3. 将在本地投资或设分支机构作为参与本地政府采购、招投标、生产经营的必要条件
4. 其他

**办法第15条 · 排斥限制外地经营者参加本地政府采购/招投标（7项）** ⚠️高频
1. 禁止外地经营者参与
2. 直接或变相要求优先采购本地登记注册经营者商品
3. 将业绩荣誉的地域、缴税社保地域、产品产地、注册地址、与本地企业组成联合体作为投标/加分/中标条件
4. 将本地区业绩、成立年限、本地奖项、本地缴税社保用于评价信用等级，或按产地设差异化信用得分
5. 按投标产品产地设差异性评审标准
6. 设不合理公示/响应时间、要求现场报名或现场购买文件
7. 其他

**办法第16条 · 对外地/进口商品要素设歧视性收费、价格、补贴（4项）**
1. 歧视性收费项目或标准　2. 歧视性价格　3. 歧视性补贴政策　4. 其他

**办法第17条 · 资质标准、监管执法方面对外地经营者歧视（4项）**
1. 规定歧视性资质、标准要求
2. 实施歧视性监管执法标准，增加检查项目或频次
3. 在投资经营规模、方式、税费水平方面规定歧视性要求
4. 其他

### 第三节 影响生产经营成本（13 项）⚠️需前置判断"有无法律行政法规依据或国务院批准"
**办法第18条 · 给予特定经营者税收优惠（4项）**
1. 减轻或免除特定经营者税收缴纳义务
2. 通过违法转换组织形式等方式变相支持少缴/不缴税款
3. 通过对特定产业园区实行核定征收等方式变相支持少缴/不缴税款
4. 其他

**办法第19条 · 给予特定经营者选择性、差异化财政奖励或补贴（5项）** ⚠️招商政策高频
1. 以直接确定受益经营者，或设置不明确、不合理入选条件的名录库/企业库等方式实施奖补
2. 根据所有制形式、组织形式等实施奖补
3. **以外地经营者将注册地迁至本地、在本地纳税、纳入本地统计等为条件**实施奖补
4. **采取列收列支或先征后返、即征即退等形式返还，或给予奖补、减免自然资源有偿使用收入**
5. 其他

**办法第20条 · 给予特定经营者要素获取/行政事业性收费/政府性基金/社保优惠（4项）**
1. 直接确定受益经营者，或设置无客观明确条件的方式在要素获取方面给优惠
2. 减免、缓征或停征行政事业性收费、政府性基金
3. 减免或缓征社会保险费用
4. 其他

### 第四节 影响生产经营行为（11 项）
**办法第21条 · 强制或变相强制经营者实施垄断行为（4项）**
1. 以行政命令、行政指导等方式强制/组织/引导实施垄断行为
2. 通过组织签订协议、备忘录等方式强制或变相强制
3. 对市场调节价商品要素，违法公开披露或要求经营者披露拟定价格、成本、产销量、客户信息等敏感信息
4. 其他

**办法第22条 · 超越权限制定政府指导价/定价、提供优惠价格（4项）**
1. 对政府指导价商品要素进行政府定价、违法提供优惠价格
2. 对本级定价目录范围外商品要素制定政府指导价/定价
3. 不执行政府指导价或定价，违法提供优惠价格
4. 其他

**办法第23条 · 违法干预市场调节价价格水平（3项）**
1. 对市场调节价商品要素制定建议价，影响公平竞争
2. 通过违法干预手续费、保费、折扣等方式干预价格水平
3. 其他

**兜底（办法第24条，1项）**：不得含有其他限制或变相限制市场准入退出、限制商品要素自由流动、影响生产经营成本、影响生产经营行为的内容。

## 三、判别要旨（决定"是否违规"的三个前置问题）

1. **是否"涉及经营者经济活动"**？不涉及的（纯民生、纯机关内部）不审查（办法第2条）。
2. **是否"给予特定经营者"优惠**？——**办法第46条定义**："特定经营者"指政策措施中**直接或变相确定的某个或某部分经营者**；**通过公平合理、客观明确且非排他性条件确定的除外**。→ 判别关键：条件是"客观、明确、非排他"（如"所有在本地注册的规上制造业企业"属客观普惠，可容忍）还是"变相确定某部分"（如"重点扶持企业""白名单""经认定"）。
3. **对外地/本地是否"同等待遇"**？凡在补助标准、申报条件、评审加分、信用评价上按**注册地、纳税地、产地、所有制**区别对待的，属高风险。

> 对"影响生产经营成本"类（第三节），还须先问：**有无法律、行政法规依据或国务院批准**？无则即使条件客观，也属违规。

## 四、例外（条例第12条 / 办法第25条）

四情形：①国家安全和发展利益；②科技进步、自主创新；③节能环保、救灾救助等社会公共利益；④法律规定或国务院批准的其他情形。
三要件：**无对公平竞争影响更小的替代方案（不可或缺 + 影响范围最小、程度最轻）＋明确合理的最短实施期限/终止条件**。
→ 例外不是"豁免"，须在审查结论中逐项论证（办法第29条列明 5 项须说明内容）。

## 五、预筛词库与信号分级

> **词库的单一事实源是脚本 `scripts/scan_rules.py`**（可执行、按事项归类、可自测）；本节只说明口径，不重复列举，避免两处各改各的、结果对不上。
> 查看当前完整词表：`python3 scripts/scan_rules.py --help` 或直接读该脚本顶部的 `RULES`。

**信号分级**

| 信号 | 含义 | 处理 |
|---|---|---|
| **强** | 命中即为高度可疑的违规结构（如「一事一议」「按地方财政贡献奖励」「零地价」「排名第 X 给予奖励」） | 优先逐条核对，多为清单主力 |
| **弱** | 定位用泛词（如「补贴」「奖励」「外地」「指定」「规划」） | 只用于圈定范围，不据此定性 |

```bash
python3 scripts/scan_rules.py policy.txt --strong-only   # 只报强信号，噪音最低
python3 scripts/scan_rules.py policy.txt                 # 强弱全报，覆盖最广
```

**结构特征信号（最易被字面词漏掉的一类）**

按「谁受益、凭什么条件受益」看，而不是看词面：

- 以「一事一议」「一企一策」「经认定 / 评审 / 审核后给予」变相确定受益对象；
- 以「白名单 / 企业库 / 名录库 / 重点扶持企业」圈定受益范围；
- 按「排名第 N」「贡献较大 / 突出」给奖——条件主观且非排他；
- 以「注册地迁入本地」「在本地纳税」「纳入本地统计」作为奖补条件；
- 以「对地方财政贡献」「税收地方留成」为奖励基数或挂钩比例；
- 奖励金额按投资额 / 营收 / 纳税额的比例或分档梯次设置。

> 三类最易漏项（泛词包装、属地条件、变相确定受益对象）的处理步骤见 `SKILL.md` 的「二、四类标准逐条扫描」第 3 步。

## 六、风险分级

| 等级 | 判定 | 处理 |
|---|---|---|
| **明显违反** | 直接命中禁止情形的实质（如"承诺N年不迁离本市"、"按财政贡献量奖励"、"购买纳入地产品目录产品给予奖励"、"行政事业性收费全免"） | 列入清单，附法条依据，建议必改 |
| **疑似** | 结构性风险（如"经认定/评审"确定受益对象、按规模分档奖补），需结合条件是否"客观明确非排他"判断 | 列入清单，标注需论证，请人工复核 |
| **提示** | 表述宽泛或涉公共资源不当挂钩（如按"贡献较大"给奖、企业子女入学指标） | 列入"提示"，建议复核，不作结论 |
